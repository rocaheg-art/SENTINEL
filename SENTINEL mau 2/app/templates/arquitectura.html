Frontend vs Backend en SENTINEL

La división de responsabilidades en el sistema

Frontend
Lo que ve el usuario en el navegador
Tablas con los registros de páginas oficiales
Formularios para registrar y editar páginas
Buscador por nombre y categoría
Pantalla de login para iniciar sesión
Mensajes de error y confirmación
Tecnologías: HTML, CSS, Bootstrap 5
Backend
Lo que procesa el servidor internamente
Verifica si una URL ya existe antes de guardar
Encripta contraseñas con bcrypt
Gestiona sesiones de usuario activo
Ejecuta consultas SELECT, INSERT, UPDATE en MySQL
Protege rutas para usuarios no autenticados
Tecnologías: Python, Flask, flask-mysqldb
